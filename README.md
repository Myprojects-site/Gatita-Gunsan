# 같이타 KSNU · 카풀 · 통학버스 프로토타입

군산대 학생끼리 동네에서 함께 타는 **카풀**과, 실제 지도 위에서 3D로 움직이는 **통학버스**를 앱 하나로 보는 프로토타입입니다.
폰으로 링크를 열면 앱처럼, 컴퓨터로 열면 폰 모양 틀 안에서 보입니다.

> 학생이 만든 비공식 프로토타입입니다. 학교 공식 서비스와 관계없고, 앱 안에서 실제 돈은 오가지 않습니다(송금은 각자 은행 앱으로).

## 기능

### 카풀
| 단계 | 하는 일 |
|---|---|
| 1. 본인 인증 | 학번(숫자 7자리, 예: 2600001) + 비밀번호로 가입·로그인. 탈 때 운전자 QR을 찍어 탑승을 인증 |
| 2. 동네 인증 | 당근마켓처럼 현재 GPS 위치로 동네 인증(30일 유지). 1km / 3km / 5km 안의 카풀만 보임 |
| 3. 카풀 올리기 | 운전자 등록(차량 번호, 계좌) 후 출발지·도착지·시간·자리·거리·1인 편도 금액 입력. 거리와 금액은 자동 추천, 직접 수정 가능 |
| 3-1. 금액 책정 이유 | 거리 × 1km당 기름값(휘발유 가격 ÷ 연비) ÷ (탑승자 + 운전자) 계산 과정을 운전자·탑승자 모두에게 보여줌. 추천과 다르게 정하면 운전자가 이유를 꼭 적어야 함 |
| 4. 신청 + 예약금 | "카풀 타기" → 예약금 송금 → 위에 **"운전자에게 예약금을 보냈어요!"** 알림. 운전자에게는 "예약금을 받았어요!" |
| 5. 단톡방 | 신청자끼리 대화, + 버튼으로 탑승 장소 제안 → 운전자가 "여기로 확정" |
| 6. 위치 공유 | 단톡방 '위치' 탭에서 켜면 같은 카풀 사람끼리 서로의 위치를 지도에서 봄. 카풀이 끝나면 자동으로 꺼짐 |
| 7. QR 탑승 인증 | 운전자 "탑승 QR" → 탑승자 "QR로 탑승 인증". 한 명이 인증할 때마다 코드가 바뀜. 카메라가 안 되면 6자리 코드 입력 |
| 8. 도착 후 송금 | 운전자 "도착했어요" → 탑승자에게 **"돈 보내기"** 버튼 → 운전자의 정산 QR을 찍으면 계좌가 보임 → 누르면 **"돈을 보냈어요!"**, 운전자에게 동시에 **"돈을 받았어요!"** |
| 9. 매너온도 | 카풀이 끝나면 운전자 ↔ 탑승자가 서로 평가 |

**매너온도를 함부로 바꿀 수 없게 한 장치**
- QR로 탑승 인증한 운전자와 탑승자 사이에서만, 카풀이 끝난 뒤에만 평가 가능 (Firestore 보안 규칙으로 서버에서 막음)
- 같은 카풀에서 같은 상대에게 한 번만, 수정·삭제 불가
- 같은 사람끼리 30일 안의 여러 평가는 마지막 1건만 반영
- 한 사람이 다른 한 사람에게 줄 수 있는 변화는 최대 ±1.0°C
- 가입 3일 이내 계정의 평가는 절반만 반영
- '별로예요'는 이유를 골라야 보낼 수 있음

**예약금 규칙**: 요금에 포함. 출발 60분 전까지 나가면 돌려받고, 그 뒤에 나가거나 안 나오면(운전자가 "안 나왔어요" 처리) 운전자에게 감.

### 통학버스
- MapLibre + OpenFreeMap으로 실제 군산·전주·익산 지도를 3D(기울기·회전·3D 건물)로 표시
- 노선: 전주 · 익산 · 군산 시내(시외 통학) + 교내 순환
- 버스가 3D 상자 모양으로 도로를 따라 움직이고, 머리 위에 "몇 분 뒤 도착" 표시
- 버스 따라가기(카메라가 버스 뒤를 따라감), 노선 전체 보기, 3D/2D 전환
- 아래 창에서 정류장별 도착 예정 시간, 오늘 운행 시간표
- 내 정보 → 시연 설정에서 기준 시각(등교/점심/하교)과 배속(10배·30배)을 바꿀 수 있음

## 두 가지 저장 방식

| | 데모 모드 (기본) | Firebase 모드 |
|---|---|---|
| 설정 | 아무것도 안 해도 됨 | `js/config.js`에 Firebase 설정 붙여넣기 |
| 공유 범위 | 같은 브라우저의 탭끼리만 | 모든 기기 (실제 사용 가능) |
| 쓰임 | 혼자 발표·시연 | 친구들과 실제로 써 보기 |

**데모 모드로 혼자 시연하기**: 같은 브라우저에서 탭을 두 개 엽니다. 한 탭은 운전자 학번, 다른 탭은 탑승자 학번으로 가입하면 두 탭이 실시간으로 이어집니다. 컴퓨터는 GPS가 없으니 동네 인증에서 "GPS가 안 될 때(테스트용)"로 같은 동네를 고르세요.

## 깃허브 페이지에 올리기

1. 깃허브에서 새 저장소를 만듭니다 (Public).
2. 이 폴더의 파일 전체(`index.html`, `css/`, `js/`, `firestore.rules`, `README.md`)를 저장소에 올립니다.
3. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 두고 Save.
4. 1~5분 뒤 `https://<아이디>.github.io/<저장소이름>/`로 열립니다.

깃허브 페이지는 https라서 폰의 GPS와 카메라(QR)가 동작합니다. (파일을 그냥 더블클릭해서 열면 카메라·위치가 막힐 수 있습니다)

## Firebase 연결하기 (여러 사람이 실제로 쓰려면)

무료(Spark) 요금제로 충분합니다.

1. https://console.firebase.google.com 에서 **프로젝트 만들기**
2. **Authentication → 시작하기 → Sign-in method → 이메일/비밀번호** 사용 설정
   (학번을 `학번@ksnu-carpool.app` 형태의 내부 이메일로 바꿔 씁니다. 실제 메일은 가지 않습니다)
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 지역은 `asia-northeast3 (서울)` 추천)
4. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**
5. **프로젝트 설정 → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값을 `js/config.js`에 붙여 넣기
   ```js
   window.FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };
   ```
6. 깃허브에 다시 올리면 끝. 내 정보 → 저장 방식이 "Firebase 연결됨"으로 바뀝니다.

`apiKey`는 공개돼도 되는 값이고, 데이터 보호는 4번의 보안 규칙이 맡습니다.

## 숫자 바꾸기

`js/data.js` 한 파일에 모여 있습니다.
- `DONGS`: 동네 인증용 군산 동네 중심 좌표
- `PLACES`: 카풀 도착지 빠른 선택
- `FARE`: 휘발유 가격(현재 1,855원/L), 연비(12km/L), 최소 금액, 예약금 기본값, 무료 취소 시간. 휘발유 가격은 [오피넷](https://www.opinet.co.kr)에서 확인해 고치면 됩니다
- `MANNER`: 매너온도 규칙(좋아요 +0.2, 별로 −0.5, 30일 규칙, ±1.0 한도, 신규 계정 3일)
- `BUS_ROUTES`: 통학버스 노선·정류장 좌표·시간표

정류장과 동네 좌표는 지도에서 대략 잡은 값이라, 실제 위치로 고쳐 쓰는 것을 권합니다.

## 프로토타입의 한계 (실서비스 전에 바꿀 것)

- **학번 인증**: 학교 학사 시스템과 연결되지 않아 입력한 학번을 그대로 믿습니다. 실서비스는 학교 SSO나 학교 메일 인증이 필요합니다.
- **송금**: 실제 송금은 은행 앱에서 하고, 앱은 "보냈어요" 기록과 알림만 남깁니다. 예약금도 기록만 합니다. 실제로 돈을 받으려면 PG(토스페이먼츠 등) 연동이 필요합니다.
- **매너온도 계산**: 평가 자체는 보안 규칙으로 막지만, 온도 계산은 각 기기에서 같은 규칙으로 합니다. 실서비스는 Cloud Functions(유료 Blaze 요금제)로 서버에서 계산하고 평가자를 숨기는 것이 좋습니다.
- **통학버스 위치**: 시간표로 계산한 위치입니다. 실제 버스에 GPS 단말이나 기사님 폰 앱을 붙이면 실시간 위치로 바꿀 수 있습니다(`js/bus.js`의 `position()`).
- **도로 경로**: OSRM 공개 서버에서 도로 경로를 받아 오고, 실패하면 정류장끼리 직선으로 그립니다. 공개 서버는 사용량이 많으면 막힐 수 있습니다.
- **알림**: 앱이 열려 있을 때 화면 위에 뜨는 알림입니다. 앱을 닫아도 오는 푸시 알림은 FCM 연동이 필요합니다.

## 파일 구성

```
index.html        화면 뼈대
css/style.css     디자인 (군산대 남색·주황)
js/config.js      Firebase 설정 (비우면 데모 모드)
js/data.js        동네·요금·매너온도·통학버스 정보
js/backend.js     저장소 (데모 모드 / Firebase)
js/bus.js         통학버스 계산 + 3D 지도
js/app.js         카풀 화면과 동작
firestore.rules   Firebase 보안 규칙
```

빌드 과정이 없습니다. 지도(MapLibre), QR(qrcode-generator, jsQR), 글꼴(Pretendard), Firebase는 인터넷에서 불러옵니다.
